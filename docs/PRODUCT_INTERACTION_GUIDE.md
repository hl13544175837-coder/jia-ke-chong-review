# 智聘独立整合版产品交互文档

## 1. 本次交付是什么

这是一个只服务于本次验收的独立电脑端项目，不会读取或修改其他产品。

- 主产品 `5190`：完整保留 Readdy ZIP 的页面、按钮、筛选、弹窗和多角色交互，并补齐原版空按钮与占位操作。
- 接口版 `5192`：保留公司招聘业务前端、独立 Flask 后端、登录桥和 GitHub 图片简历解析能力，供研发后续接真实接口时参考。
- 后端 `5010`：独立 Flask + SQLite 演示数据。
- 登录桥 `5110`：只给接口版提供本地登录映射。
- 正式业务 API、公司 OAuth、LLM 和视觉模型密钥本轮不开发，只保留接口位置和数据格式。
- 只验收电脑端，不做手机端。

## 4. 关键交互

### 工作台与招聘管理

- 工作台待办、月份、岗位进度、数据概览和统计入口均可点击。
- 岗位列表支持搜索、状态切换、筛选、排序和阶段下钻。
- 岗位详情支持编辑名称，保存后当前详情立即更新。
- “上传新简历”会打开完整上传弹窗，支持多选并更新当前岗位候选人列表。

### 简历库

- 支持姓名/职位搜索、状态页签、来源、负责人、部门、经验、学历、性别、标签和最近动态筛选。
- 支持 PDF、DOC、DOCX、JPG、JPEG、PNG、WebP、GIF 和 ZIP。
- 图片与 ZIP 在本地走演示解析，导入后新增候选档案、来源和结果提示。
- 支持批量绑定岗位、推送面试官、分配负责人、加标签、导出和取消选择。
- 候选人“…”菜单支持完整简历、应聘历史、编辑档案、加入其他岗位和人才池操作。

### 面试、Offer 与看板

- 面试列表与日历、筛选、安排、调整、评分、处理结果和候选人历史均保留。
- Offer 支持状态筛选、审批、发放、跟进、入职、撤回、重发、导出和历史记录。
- 进度看板支持阻塞分析、招聘专员和总览三种视图。
- 月份按钮会真实切换报表月份并显示结果提示。

### 系统设置

- 通用设置可保存公司名、系统名和招聘周期。
- 用户可以新增、编辑、停用和重新启用。
- 角色权限勾选后可以保存演示状态。
- 部门可以新增、编辑和删除。
- 招聘流程阶段可以上移、下移，首尾按钮明确禁用。

## 5. “所有按钮都有且可交互”的验收口径

原 ZIP 静态清单：

- 718 个交互控件。
- 其中 479 个原生按钮。
- 原版存在 3 个完全没有处理逻辑的按钮。
- 原版存在 11 个点击后只显示“功能开发中”的占位操作。

整合后的主产品：

- 754 个交互控件，完整覆盖原版 718 个，缺失数为 0。
- 499 个原生按钮，包含原版按钮和新增的完整操作控件。
- 没有处理逻辑的按钮为 0。
- “功能开发中”占位操作为 0。
- 所有无法在当前状态执行的按钮使用 `disabled`；可执行按钮必须导航、筛选、切换、打开弹窗、下载或产生可见状态变化。

复跑严格审计：

```bash
node frontend/tests/readdy_zip_exact_parity.test.mjs
```

该测试会逐文件核对原 ZIP 控件标签与数量，并检查空按钮、占位文案、24 条路由和图片/ZIP 格式。

## 8. 演示边界

- 主产品的新增、编辑和筛选状态保存在当前浏览器内存，刷新后会恢复演示数据。
