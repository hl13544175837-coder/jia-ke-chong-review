# 智聘 · 同事小范围试用说明

## 1. 怎么打开

- 本地地址：`http://127.0.0.1:5190`
- 统一测试密码：`Zhipin2026`
- 只使用测试数据，不上传真实候选人的姓名、电话、邮箱、简历或其他隐私信息。

## 2. 测试账号

| 测试视角 | 账号 | 主要检查内容 |
|---|---|---|
| 管理员 | `admin01` | 系统设置、角色权限、整体页面 |
| 招聘专员 | `hr01` | 招聘需求、简历库、面试安排、Offer |
| 一面面试官 | `interviewer01` | 招聘需求、待筛选、我的面试、一面评价 |
| 二面面试官 | `interviewer02` | 二面任务、历史评价可见范围、二面评价 |
| 人力资源总监 | `director01` | 管理驾驶舱、招聘进展、人才储备、审批风险、数据看板 |

## 3. 推荐测试顺序

1. 招聘专员进入“招聘需求”，打开整行详情并确认岗位信息。
2. 招聘专员从需求进入候选人，查看简历并安排一面。
3. 一面面试官查看任务、申请改约或提交本轮评价。
4. 招聘专员处理改约、查看评价并安排下一轮。
5. 二面面试官完成二面评价，确认只能看到允许查看的历史信息。
6. 招聘专员查看完整过程并进入 Offer 流程。
7. 人力资源总监查看只读管理数据，管理员检查角色与系统设置。
8. 每个角色切换两次左侧菜单，确认筛选仍保留、旧详情不会自动重新弹出。

## 4. 这次重点观察什么

- 左侧菜单名称和页面顶部不再重复出现同一个大标题。
- 页签选中状态都是绿色实心框。
- 点击列表整行可以查看详情，关闭后页面仍能继续点击和滚动。
- 切换页面再返回时，页签和搜索条件保留，但已经关闭的详情不重开。
- 保存或提交期间按钮不可重复点击，也不能误关弹窗。
- 空数据、加载失败和操作失败时，页面会说明原因或提供重试入口。
- 如果某个页面异常，系统提供“重新加载”和“返回工作台”，不会只剩白屏。

## 5. 本轮暂时不测

- AI 简历解析和模型推荐。
- 企业微信、短信、邮件、外部日历通知。
- OA 自动审批、BOSS 自动化和其他外部接口。
- 公司正式数据库、真实账号、真实候选人数据和生产权限。
- 公司 Test/SIT 部署结果；本说明只对应本地版本。
