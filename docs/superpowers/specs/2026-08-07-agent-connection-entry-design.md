# Agent 连接入口设计

## 目标

修复“后端已经能接收外部 Agent 导入，但招聘专员无法在产品里完成接入”的技术债。招聘专员在“在线简历”页面内选择一个自己的有效招聘需求、填写对应 BOSS 账号，系统生成限权凭证和完整提示词，用户一次复制给 Ego 或其他支持 HTTP 请求的 Agent。

## 已验证前提

2026-08-07 已用 Ego 进程真实调用隔离环境：在线简历导入返回 `created=1`；完整 PDF 导入返回 HTTP 202，候选人进入指定 Demand 的 `pending` 阶段。智聘侧反查到原始文件、结构化信息、负责人、Demand 和 `agent.full_resume.imported` 收据。

## 用户流程

1. 招聘专员进入“在线简历”。
2. 点击“连接 Agent”。
3. 选择一个本人可管理且状态为 `active` 的招聘需求。
4. 填写当前使用的 BOSS 账号名称。
5. 点击“生成连接提示词”。前端调用现有 `POST /api/agent-imports/token`，生成默认 30 天的限权凭证。
6. 页面展示包含接口地址、招聘需求、JD、BOSS 账号、两类导入规则和凭证的完整提示词，用户点击“一键复制”。
7. 关闭弹窗后清空凭证和提示词，不写入本地存储或业务日志。

## 范围

- 复用现有限权凭证和两个导入接口，不新增数据库表或审批状态。
- 复用现有招聘需求列表，只展示 `active` 且当前招聘专员可见的需求。
- 提示词同时覆盖选择性在线简历导入、完整聊天保留、完整简历原件上传和稳定外部编号。
- 智聘仍不启动、不控制外部 Agent，也不在产品内发送 BOSS 消息。

## 页面与组件

- 在线简历页标题区新增主按钮“连接 Agent”。
- 新建 `AgentConnectionDialog`，独立负责需求加载、BOSS 账号输入、凭证生成、提示词构建、复制、错误与关闭清理。
- `onlineResumesApi` 增加生成限权凭证的方法。
- API 工具导出“当前外部可用 API 地址”的解析方法：相对 `/api` 使用当前页面域名，绝对网关地址保持原值。

## 安全与失败处理

- 只有招聘专员能生成凭证，后端现有 RBAC 保持最终边界。
- 普通登录 Token 不写入提示词；只写入 `agent_import` 限权凭证。
- 凭证只在当前弹窗内存中存在，关闭即清空；不进入 URL、localStorage、日志或验收截图。
- 没有有效需求时只给出明确说明，不允许生成。
- 需求加载、凭证生成或复制失败时显示大白话错误，可原地重试。
- 提示词明确：云端 Agent 不能使用 `127.0.0.1`；本地地址只适合同一台电脑上的 Ego。

## 验收

- 契约测试确认真实调用 `/agent-imports/token`，没有 Mock 或硬编码 Token。
- 提示词包含 API 地址、Demand ID、JD、BOSS 账号、在线与完整简历接口、稳定编号和保密要求。
- 类型检查、Lint、构建、后端全量、前端契约和招聘专员浏览器流程全部通过。
- 浏览器验收只确认生成与复制交互，不在日志或截图中输出凭证明文。
