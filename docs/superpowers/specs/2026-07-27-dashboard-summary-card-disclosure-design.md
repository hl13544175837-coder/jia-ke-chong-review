# 工作台概览卡折叠交互设计

## 目标

工作台默认只显示四张概览卡，避免卡片统计和下方明细同时常驻造成信息重复。用户点击卡片后，才展开与该卡片一一对应的明细；再次点击同一卡片收起。

## 交互规则

- 默认不展开任何明细，首屏只保留“剩余 HC”“我的待办”“等待他人处理”“近期面试”四张卡片。
- 同一时间最多展开一个明细板块。点击另一张卡片时，当前板块收起并切换到新板块。
- 展开的卡片用浅绿色边框和背景表示选中状态，并显示向上箭头；未展开卡片显示向下箭头。
- 四张卡片与内容固定对应：
  - 剩余 HC → 生效需求进展
  - 我的待办 → 我的待办列表
  - 等待他人处理 → 等待他人处理列表
  - 近期面试 → 近期已排面试
- 卡片使用真正的按钮元素，支持键盘操作，并通过 `aria-expanded` 和 `aria-controls` 表达展开关系。
- 数据来源、列表内部操作和跳转地址保持不变，不修改后端接口和技术栈。

## 验收标准

- 初次进入工作台时，四个明细板块均不渲染。
- 点击任一卡片只出现对应明细，再次点击后消失。
- 从一张卡切换到另一张卡时，页面上只保留后一张卡对应的明细。
- 刷新数据不会强制展开或切换板块。
- 桌面端四卡一排、窄屏两卡一排，按钮布局无重叠。
