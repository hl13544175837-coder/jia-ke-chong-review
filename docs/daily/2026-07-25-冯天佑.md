## 思考性工作

- 方案选择：PDF/DOCX 转图片统一走视觉模型，而非保留文本提取管线。理由是视觉模型对中文简历的复杂排版（双栏、表格、缩进）理解远优于文本提取 + LLM。
- DOCX 转图片：因项目环境无 LibreOffice，选择用 PIL 直接绘制文本为图片页的方式，零外部依赖。
- 多页合并：每页独立调视觉模型提取各自字段，最后按字段合并（标量字段取第一个非空值，列表字段拼接），保证多页简历信息不丢失。

## 遗留风险

- DOCX 的 PIL 渲染为纯文本图片，无法还原原文档的排版和格式（如表格边框、对齐），对于格式复杂的 DOCX 可能有信息损耗。
- 多页文档每页一次 API 调用，页数多时代价较高，可考虑多图一次请求的方式优化。
