## 3. 五个角色逐项验收

每个角色都要做四件通用检查：打开一条详情并关闭；切换菜单再返回；确认页签/搜索仍保留；确认关闭的详情不会再次盖住页面。若自然出现空数据或加载失败，还要确认页面有大白话说明，加载失败时可以点“重新加载”。

### 招聘专员 `hr01`

- [ ] 招聘需求：打开整行详情，关闭后页面能继续点击和滚动。
- [ ] 简历库：用“验收测试”记录检查筛选、详情和返回状态。
- [ ] 面试管理：查看待安排、已安排、待反馈，检查改约记录和下一步入口。
- [ ] Offer：切换状态、搜索并返回，筛选条件保持。
- [ ] 权限符合预期：能处理招聘流程，不能进入管理员系统设置。

### 一面面试官 `interviewer01`

- [ ] 招聘需求：整行可打开只读详情，关闭后不会留下灰色遮罩。
- [ ] 待面试官筛选：打开候选人详情，切换菜单后页面仍可点击。
- [ ] 我的面试：查看一面任务和历史记录，不提交真实评价。
- [ ] 改约：只检查申请入口、历史留痕和提示，不改动非测试记录。
- [ ] 权限符合预期：看不到招聘专员的 Offer 操作和管理员设置。

### 二面面试官 `interviewer02`

- [ ] 我的面试：能识别二面任务、时间和对应岗位。
- [ ] 历史信息：只能看到业务允许展示的上一轮信息。
- [ ] 打开并关闭详情，再切换菜单返回，状态不丢且无残留遮罩。
- [ ] 权限符合预期：不能修改招聘需求、Offer 或系统设置。

### 人力资源总监 `director01`

- [ ] 工作台：招聘进度、人才储备和风险提醒能正常打开。
- [ ] 数据看板：入口在人才地图下面，数据内容符合总监视角。
- [ ] 切换看板范围后离开再返回，当前选择仍保留。
- [ ] 权限符合预期：管理视角以查看为主，不出现不该有的业务提交按钮。

### 管理员 `admin01`

- [ ] 系统设置：角色和账号列表能打开，详情能正常关闭。
- [ ] 核心业务页：加载、空状态和错误提示样式一致。
- [ ] 数据看板：显示管理员可看的整体数据。
- [ ] 权限符合预期：能查看管理配置，但不代替业务角色提交测试决策。
