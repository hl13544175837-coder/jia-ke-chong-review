# 企业内部招聘管理系统

## 1. 项目描述
面向公司内部的招聘管理系统（ATS），帮助招聘专员、面试官、招聘主管和管理员高效协作，覆盖从招聘需求澄清、岗位发布、简历筛选、面试安排到反馈评估的全流程。核心价值是信息聚合与流程可视化，让招聘团队告别信息碎片化。

**目标用户（4个角色）：**
- **招聘专员**：发布岗位、筛选简历、安排面试、跟进候选人
- **面试官**：查看分配的面试任务、提交面试反馈
- **招聘主管**：审批招聘需求、查看团队招聘进度、数据看板
- **管理员**：系统配置、角色权限管理、所有数据可见

## 2. 页面结构
- `/` — 登录页
- `/dashboard` — 工作台（不同角色看到不同的数据看板）
- `/jobs` — 岗位管理（职位列表、发布/编辑职位）
- `/jobs/:id` — 岗位详情（候选人流程、面试安排）
- `/candidates` — 候选人管理（简历库、筛选状态）
- `/candidates/:id` — 候选人详情（简历解析、面试记录、反馈）
- `/requisitions` — 招聘需求管理（需求提交、审批流程）
- `/interviews` — 面试管理（排期、反馈收集）
- `/settings` — 系统设置（角色权限、部门配置等，管理员专有）

## 3. 核心功能
- [ ] 用户登录 & 角色权限控制
- [ ] 工作台 Dashboard — 关键指标可视化（各角色不同视图）
- [ ] 岗位管理 — 创建、编辑、发布/下架岗位
- [ ] 候选人管理 — 简历入库、状态流转、标签分类
- [ ] 招聘需求 — 需求提交 → 审批流程
- [ ] 面试管理 — 排期安排、面试反馈录入
- [ ] 数据统计 — 招聘漏斗、周期分析

## 4. 数据模型设计
（后续连接 Supabase 后细化）

### 核心表：
- **users** — 用户（姓名、邮箱、角色、部门）
- **jobs** — 岗位（标题、部门、状态、JD描述、发布人）
- **candidates** — 候选人（姓名、联系方式、简历文件、当前状态、来源）
- **applications** — 投递记录（候选人 ↔ 岗位、状态流转）
- **requisitions** — 招聘需求（申请人、部门、人数、紧急程度、审批状态）
- **interviews** — 面试安排（候选人、岗位、面试官、时间、反馈）
- **feedback** — 面试反馈（面试官评价、评分、是否通过）

## 5. 后端 / 第三方集成计划
- **Supabase**：用户认证 + 数据库 + 文件存储（简历文件）
- **无需支付/电商集成**

## 6. 开发阶段计划

### Phase 1：整体框架 + 工作台页面
- 目标：搭建整体布局框架（侧边导航 + 顶栏），完成工作台 Dashboard 页面 UI
- 交付物：登录页 UI、主布局组件、工作台页面（含统计卡片、图表、待办事项等 mock 数据）

### Phase 2：岗位管理 + 候选人管理页面
- 目标：完成岗位列表/详情页和候选人列表/详情页
- 交付物：岗位 CRUD 页面、候选人管理页面、简历查看

### Phase 3：招聘需求 + 面试管理页面
- 目标：完成需求审批流程页面和面试排期/反馈页面
- 交付物：需求列表、需求详情、审批操作、面试日历、反馈表单

### Phase 4：系统设置 + 角色权限
- 目标：完成设置页面，实现角色路由守卫
- 交付物：用户管理、角色配置页面、权限控制

### Phase 5：连接 Supabase（数据 + 认证）
- 目标：将 mock 数据替换为真实数据，接入认证系统
- 交付物：注册/登录功能、数据持久化、角色权限生效
